# Contributing

This repository is the public-facing Replication product surface.

Use GitHub issues for non-security documentation, reproducibility, and product questions that contain no credentials, provider coordinates, retained evidence, personal data, or private operational details.

Security-sensitive reports must use GitHub Private Vulnerability Reporting / GitHub Security Advisories rather than an ordinary public issue. See `SECURITY.md`.

Changes must preserve immutable-publication, target-binding, collision-refusal, and fail-closed readback semantics. Do not add credential authority, IAM/provisioning authority, mutable-overwrite behavior, or a second evidence authority.
